《永夜微光》· 游戏设计方案

末世生存经营 + 光暗攻防  |  微信小游戏  |  MVP Demo 确认稿
经营养成俯视 2D 点击建造卡通 2.5D 光照灼伤/减速生产建筑 + 科技树单局 15–20 分钟

01 一句话定位

白天靠光源圈地发展，夜晚抵御每 10 天进化一次的怪物潮，撑过 100 天。

末世不等于丧尸。怪物是一套会进化的生态，而光既是人类的庇护所，也是对怪物的武器。

02 核心循环

白天：建造 / 生产 / 点科技 → 入夜：怪物来袭 → 光照灼伤 · 减速 · 清怪 → 结算 · 天数 +1 → 每 10 天进化 → 第 100 天胜利

04 核心机制拆解

4.1 光暗系统（签名机制）

光内不刷怪持续灼伤进入减速

光源由玩家建造并升级，形成可扩展的安全区。怪物只在黑暗中刷新；进入光照范围后会持续掉血并被减速，越靠近光源伤害越高。这让「扩光」同时是发展手段和防御手段。

篝火
低成本、小范围，前期主力
灯塔
高成本、大范围，中后期扩张
移动光源
跟队/巡逻，主动清怪

4.2 昼夜节奏

单局时长15–20 分钟（100 天）
1 天时长约 8–12 秒
昼 : 夜约 7 : 3（白天发展，夜晚攻防）
加速支持 1x / 2x / 3x 快进

4.3 经营系统

资源（建议 3 种）
木材建造 / 基础科技
石料防御 / 高级建筑
能源光源 / 科技研究
科技树（建议 4 支）
光照光范围 / 灼伤强度
防御塔 / 城墙 / 陷阱
经济产出效率 / 存储上限
兵种守卫 / 巡逻单位

4.4 怪物体系与进化

僵
普通僵尸 · 近战
数量多、血薄，成群冲击，基础压力来源。
骷
骷髅弓箭手 · 远程
隔墙/远程射击，迫使玩家考虑视野与站位。
爆
绿色自爆体 · 爆炸
靠近即自爆，对建筑与光源造成范围伤害。
影
黑色高个 · 瞬移
可瞬移越过防线，直扑核心，后期高危单位。
每 10 天进化：建议进化为「数值强化 + 解锁新兵种 / 新技能」双轨。例如第 20 天骷髅学会齐射、第 40 天黑影可携自爆体瞬移。进化节点配合 BOSS/波峰，形成十天的压力阶梯。

4.5 胜负条件

胜利存活满 100 天
失败核心建筑被摧毁
评价按剩余核心血量 / 建筑数 / 天数评分

05 美术与资产管线

风格
卡通 2.5D，圆润造型、暖色调光源与冷色夜景强对比。
图片（Image 2.5）
角色、建筑、怪物、地面/场景精灵，统一出图提示词与色板。
动效（SD 2.5）
爆炸、灼烧、升级、波次登场等短演出，转序列帧/精灵动画。
规范建议：统一 2x 分辨率出图后按图集（atlas）打包；光源采用叠加贴图 + 遮罩实现「光内不刷怪」与灼伤范围可视化；控制单张图集 ≤ 1024，兼顾小游戏包体限制。

06 技术方案（MVP）

运行平台微信小游戏（Canvas，非小程序页面）
渲染flova 画布框架（适配层独立抽象）
游戏循环固定步长 update + 渲染解耦
核心模块实体系统 / 光照网格 / 波次管理 / 建造系统 / 科技树 / 存档
输入俯视点击落位建造、拖拽调度、双指缩放
数据本地存档（wx.setStorage），JSON 配置驱动数值

flova 适配层统一封装：canvas 初始化、精灵/图集加载、音频播放、触摸事件、帧循环。其余逻辑与平台无关，方便后续替换引擎或移植。
