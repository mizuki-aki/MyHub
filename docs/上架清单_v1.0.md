## 1. 账号与资质（你办，决定总时长）

### 1.1 注册与取名

- [ ] 打开 mp.weixin.qq.com，注册类型选 **小游戏**（不是小程序，入口不同）
- [ ] 主体类型选 **个人**，完成实名（身份证 + 人脸）
- [ ] **先查名称「永夜微光」是否可用**——名称全平台唯一，被占用就得换
- [ ] 想好 2~3 个备选名（例：车灯不灭 / 永夜公路 / 一车一灯）

### 1.2 拿到 AppID 并填进项目

- [ ] 后台「开发 → 开发设置」复制 AppID
- [ ] 填进 `minigame/project.config.json` 的 `appid` 字段，替换 `touristappid`

> 这一步做完，开发者工具就能真机预览了。**建议先做这一步**，后面等资质的时候可以先在真机上验一遍。

### 1.3 版权证明（周期最长，越早办越好）

游戏类目必须提供版权证明，个人主体两条路：

| 路径 | 出证周期 | 花费 | 说明 |
|---|---|---|---|
| **电子版权认证报告** | 约 3~7 个工作日 | 约几百元 | 快，多数休闲小游戏走这条 |
| **计算机软件著作权** | 普通 30~60 工作日；加急 3~5 工作日 | 加急约千元级 | 效力最全，后续上其他平台也认 |

- [ ] 二选一办下来
- [ ] ⚠️ **证书上的游戏名称必须与后台小游戏名称完全一致**，差一个字都可能要求补授权书或改名——所以顺序是：**先定名 → 再办证**，不要反过来
- [ ] 软件名称建议写成「永夜微光游戏软件」这类规范格式，与游戏名对应

### 1.4 个人主体的三个限制（提前知道，免得白做）

1. **不能开通虚拟支付**，也就做不了内购。本作按纯免费设计，不受影响。
2. **不能申请游戏版号**（版号需企业主体）。走电子版权 / 软著即可，不需要版号。
3. **流量主广告**需要先上线并达到平台要求的访问量才能申请，所以第一版没有广告收入是正常的。

### 1.5 服务类目

- [ ] 后台「设置 → 基本设置 → 服务类目」添加：**游戏 → 休闲游戏**
- [ ] 类目需要上传 1.3 的版权证明，没有证明这一栏过不去

### 3.1 用户隐私保护指引

- [ ] 后台「设置 → 服务内容声明 → 用户隐私保护指引」填写并提交

本作的处理方式：**不收集任何用户信息**。不调 `wx.login`、不取手机号、不取位置、不联网、不接任何统计 SDK。只用了本地存储（最好成绩、进度存档）和震动。

- 收集信息一栏：选「不收集」
- 若表单强制要求至少填一项，按实际用途只勾「剪切板/存储」类中与本地缓存相关的项，并说明"仅用于保存本地游戏进度，不上传"

### 3.2 游戏自审自查报告

- [ ] 后台下载《游戏自审自查报告》模板
- [ ] 按实际内容填写：题材（末世公路生存）、玩法（换道搜刮 / 塔防布守）、无付费、无社交、无 UGC、无用户输入
- [ ] 个人主体：本人签字 + 按手印/身份证号，扫描或拍照上传

> 内容自查要点：本作没有文字输入、没有玩家间通讯、没有抽奖/开箱、没有真实货币交易，这几点写清楚能显著降低审核问询概率。

## 4. 提审与发布（你操作）

- [ ] 开发者工具打开 `minigame/` 目录
- [ ] 点「上传」，版本号填 `1.0.0`，备注写「首个版本」
- [ ] 后台「版本管理 → 开发版本 → 提交审核」
- [ ] 审核信息里勾选已配置的服务类目、已上传的资质
- [ ] 等待审核：休闲游戏通常 1~2 天，遇问询按提示补材料
- [ ] 审核通过后点「发布」

### 常见驳回原因（提前规避）

| 原因 | 本作的应对 |
|---|---|
| 类目与内容不符 | 已按「休闲游戏」设计，无付费无社交，一致 |
| 缺少版权证明 | 必须先办下来再提审，否则一定卡住 |
| 名称与资质不一致 | 定名后办证，保证一致 |
| 截图与实际不符 | 截图全部是真机渲染的真实画面，不含宣传语 |
| 未成年人保护 | 无付费、无社交、无诱导，风险低 |
| 首次进入白屏/黑屏 | 已在多机型验证首帧渲染；若有问题把机型反馈给我 |

## 5. 建议的执行顺序（省时间）

```
今天：注册小游戏账号 → 查名称 → 拿到 AppID 填进配置
     ↓（AppID 一到手就能真机预览，不用等资质）
今天：定名 → 立刻提交电子版权认证申请（这条最长）
今天：我把代码和物料都交付（已完成）
     ↓
等证期间：真机验证 + 后台填隐私指引、自审报告、上传图标截图
     ↓
证书下来：配置服务类目 → 上传代码 → 提审
     ↓
1~2 天后：审核通过 → 发布
```

不可压缩的只有版权证明那几天。其余都是当天能完成的。

## 6. 上线之后（暂不做，记录备查）

- **流量主广告**：达到平台访问量要求后申请，可挂激励视频（复活 / 双倍搜刮），但会改动数值平衡，需重新回归
- **排行榜**：需要后端或开放数据域，个人主体也能做，但要额外开发
- **版本更新**：小游戏会自动更新，无需 `wx.getUpdateManager`（那是小程序的 API）
