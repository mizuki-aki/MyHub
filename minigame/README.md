# 永夜微光 · v1.1 碰碰车（微信小游戏）

末世公路生存：开着越野车一路向前。白天**拖车撞悬浮球**搜刮，黄昏布防，夜晚守车。**坚守 100 天** 或 **开过 800 户抵达救援中心** 即胜利。

> 这是**微信小游戏**工程（Canvas 渲染，`game.js` 入口），不是小程序，没有 WXML 页面。

## 目录

```
minigame/
├── game.js             入口：wx.createCanvas / 资源加载 / 触摸与拖拽绑定
├── game.json           竖屏配置
├── project.config.json compileType: game
├── js/core.js          平台无关核心（几何 / 驾驶 / 战斗 / 渲染，约 1750 行）
├── js/assets.js        素材清单（tools/build_preview.py 自动生成）
└── images/{char,monster,building,ui,tile}
```

用微信开发者工具导入 `minigame/` 目录即可运行（AppID 可用测试号）。

## 一天 60 秒

| 阶段 | 时长 | 你在做什么 |
|---|---|---|
| ① 行进 | 15s | 车自动前进，**拖屏幕左右控车**，撞破外道悬浮球补给。能量每跨 1 户 −1 |
| ② 黄昏布防 | 15s | 建造 **0 耗时**，纯思考。可暂停 1 次 10s，可「直接布防」换时间 |
| ③ 夜晚防守 | 30s | 建/修各 1s（加速药 0.5s），篝火烧怪、箭塔输出、怪拆你建筑 |

行进用不完的时间会**并入黄昏**，所以升级车速 = 换布防时间。

## 白天：碰碰车

- 车宽 **1 条车道**，在 5 道里横移；目标车道由手指拖动设定，车按 `TURN_STEP` 滑过去（有迟滞，不是瞬移）
- 每天 8 个**悬浮球**，只挂最外侧两车道，按「左左右右」成对分布 —— 4 次横穿即可拿满
- 撞上即触发搜刮 1.4s，期间**车不动但倒计时照走**；开过即永久错过
- 四类球靠颜色 + 图标区分：民房 / 超市 / 医院 / 工厂

**关键门槛**：搜刮 8 个 = 11.2s，15s 只剩 3.8s 行驶。Lv1/Lv2 只能推进 **7 户**，**Lv3 才能推满 8 户**。800 户 ÷ 100 天 = 每天 8 户，所以不升车速就拿不到「抵达救援中心」这条线。

## 战场几何

竖版，整体顺时针旋转 **15°**，让公路斜着往上，既保留纵深感又不呆板。

- **5 车道 × 9 行**纵深格，一维坐标 `v`：`v=0` 是车的位置，`v=9` 是地平线
- 相机跟车：车在屏幕上固定画在 `v=0.30`，其余物体按「相对纵深 + `CAR_V0`」叠加
- **透视收敛**：远端路宽 = 近端 46%，格子与怪物随深度缩放
- 世界坐标 ↔ 屏幕坐标走 `w2s()` / `s2w()`；点屏幕 → 反旋转 → 反透视 → `cellAtScreen()` 得 `{col,row}`
- 布防阶段路面浮现淡网格，行进时自动隐藏

## 输入接线

`core.js` 通过 `env` 注入两个回调，两端各自实现：

| 回调 | 微信（game.js） | 浏览器（预览页） |
|---|---|---|
| `onPointer(x, y)` | `wx.onTouchStart` | `pointerdown` |
| `onDrag(phase, x, y)` | `onTouchStart / Move / End / Cancel` | `pointerdown / move / up / cancel` |

`phase` 取 `'down' | 'move' | 'up'`。白天走 `onDrag` 控车，黄昏/夜晚走 `onPointer` 点格子。
